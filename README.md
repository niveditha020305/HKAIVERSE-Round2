# Curriculum Intelligence Challenge — CSE 2030

## Overview

This project analyzes the current B.Tech Computer Science and Engineering curriculum under JNTUH R22 regulations and proposes an evidence-based curriculum for students graduating in 2030.

The analysis focuses on identifying which subjects should be **KEEP, UPDATE, REDUCE, or ADD**, based on changes in technology, industry requirements, academic curriculum, and evidence from relevant sources.

## Project Objectives

1. Analyze the existing R22 CSE curriculum.
2. Compare R22 with the newer JNTUH R25 curriculum.
3. Identify important changes in the technology and software industry.
4. Analyze relevant job requirements.
5. Evaluate existing subjects using KEEP, UPDATE, REDUCE, and ADD labels.
6. Design a balanced proposed curriculum for 2030.
7. Support curriculum changes with evidence and sources.
